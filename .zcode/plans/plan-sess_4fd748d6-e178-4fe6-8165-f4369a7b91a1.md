## 概览
将 `integrate-boot` 项目从 Maven 转为 Gradle（Kotlin DSL），采用 java-platform 实现 BOM，并在 `modules/` 下创建 `integrate-boot-data` 子模块。

## 目标结构
```
integrate-boot/
├── settings.gradle.kts          # 根设置，声明 include("bom"), "modules:integrate-boot-data"
├── build.gradle.kts             # 根构建脚本（不应用 java 插件）
├── gradle.properties            # 版本与依赖坐标集中声明
├── gradle/
│   ├── wrapper/
│   │   ├── gradle-wrapper.jar
│   │   └── gradle-wrapper.properties      # Gradle 8.14+，兼容 JDK 25 / Spring Boot 4
│   └── libs.versions.toml        # Version Catalog（推荐方式集中管理依赖）
├── gradlew / gradlew.bat
├── bom/
│   └── build.gradle.kts          # java-platform 插件，发布 BOM
└── modules/
    └── integrate-boot-data/
        └── build.gradle.kts      # java + java-library 插件，data 模块
```

## 实施步骤

### 1. 删除 Maven 文件
- 删除根 `pom.xml`
- 删除 `bom/pom.xml`（bom 目录改放 `build.gradle.kts`）

### 2. 创建根 Gradle 配置
**`settings.gradle.kts`**
- `rootProject = "integrate-boot"`
- `include("bom")`、`include("modules:integrate-boot-data")`
- 把子模块名重命名为 `integrate-boot-data`（默认即此名）
- 启用 `dependencyResolutionManagement { repositories { mavenCentral() }; versionCatalogs }`，从 `gradle/libs.versions.toml` 创建 `libs` catalog

**`gradle/libs.versions.toml`**（Version Catalog，集中管理依赖版本）
- `spring.boot = "4.1.0"`、`mybatis.flex = "1.11.8"`
- `libraries`：`spring-boot-dependencies`（platform）、`mybatis-flex-spring-boot4-starter`、以及 data 模块常用 starter（`spring-boot-starter`、`spring-boot-starter-jdbc`、`mybatis-flex-spring-boot4-starter`）

**`gradle.properties`**
- `group=com.github.henc`
- `version=0.0.1-SNAPSHOT`
- `org.gradle.caching=true`、`org.gradle.parallel=true`

**根 `build.gradle.kts`**
- 仅做 group/version 兜底与通用配置；不应用 java 插件（根是聚合项目）

### 3. bom 模块（`bom/build.gradle.kts`）
- `plugins { `java-platform` }`
- `dependencies { constraints { api(libs.mybatis.flex.spring.boot4.starter) ... } }` 声明所有版本约束
- 通过 `javaPlatform { allowDependencies() }` 允许导入 spring-boot-dependencies 作为 platform

### 4. data 子模块（`modules/integrate-boot-data/build.gradle.kts`）
- `plugins { `java-library` }`
- `dependencies { api(platform(libs.spring.boot.dependencies)); api(libs.mybatis.flex.spring.boot4.starter) ... }`
- Java 工具链 JDK 25（与 IDEA 配置一致）

### 5. Gradle Wrapper
- 创建 `gradle/wrapper/gradle-wrapper.properties`（distributionUrl 指向 Gradle 8.14.2）
- 由于本机无 gradle，需通过下载 wrapper jar + 脚本的方式生成 `gradlew` / `gradlew.bat` 与 `gradle-wrapper.jar`（我会直接写入这些二进制/脚本文件）

### 6. .gitignore 更新
- 添加 Gradle 构建产物忽略项：`.gradle/`、`build/`、`!gradle-wrapper.jar`（wrapper jar 需提交），同时保留对 IDEA 的忽略

### 7. README 更新
- 简要说明项目结构（bom + modules）与构建方式（`./gradlew build`）

## 校验
- 运行 `./gradlew projects` 确认包含 `bom` 与 `modules:integrate-boot-data` 两个子项目
- 运行 `./gradlew :modules:integrate-boot-data:dependencies` 确认依赖解析正常（mybatis-flex、spring-boot-dependencies）
- 如校验失败会回报原始输出

## 风险与说明
- Gradle wrapper jar 是二进制文件，需从官方下载（distributionSha256Sum 校验）；如网络受限可能失败，届时会提示
- Spring Boot 4.1.0 + JDK 25 需要 Gradle 8.14 及以上，wrapper 会固定版本
- Version Catalog 是 Gradle 现代依赖管理推荐做法，替代原 Maven 的 `dependencyManagement`
